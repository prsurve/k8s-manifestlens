ManifestLens

Kubernetes manifest intelligence

Runs in your browser. Nothing is uploaded.

VS Code GitHub

Your manifests are parsed and checked inside this page and are never sent anywhere. The page itself makes two kinds of request: anonymous page-view analytics, and a download of a CRD only when you press Load on a GitHub link.

Sample manifests:

Custom rules (used by Check, Diff and Fix) 0 rules

Plain YAML, one rule or several separated by ---. See the rule guide.

Custom resources (CRDs) (used by Explain, Check, Diff and Fix) 0 kinds

Paste the CustomResourceDefinition YAML, for example from kubectl get crd NAME -o yaml. Fields of that kind are then explained and checked against its schema. Nothing leaves your browser unless you load a URL.
